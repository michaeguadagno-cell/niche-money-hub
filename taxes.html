Questions?

What is Oct 15?

If you already asked the IRS for extra time, most people then file by Oct 15. That extra time is to file, not to pay. This page does not file for you. Not tax advice.

Does this file my whole tax return?

No. It makes the coin-trade report. You still file job taxes the way you already file — an app, Free File, or a tax person.

I already clicked file in the usual app.

That app does the job pile. It does not see wallets unless you add them. This makes the coin report to put with that file. It does not find extra job credits. Not tax advice.

I only have a job. No coins.

Then you do not need this button. File the usual way. This page is for both piles.
